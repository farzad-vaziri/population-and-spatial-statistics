# Population and spatial statistics

A collection page of live dashboards on where people live and how far models can be trusted when they have to estimate it: rebuilding Ghana's 2021 census on a 100 m grid from 16 regional totals, and who is invisible to mobile-phone data in Nigeria.

**Live page:** https://farzad-vaziri.github.io/population-and-spatial-statistics/

One static page (`index.html`) served by GitHub Pages from `main`. Images are in `assets/previews/`, and fonts (Barlow and Barlow Condensed, SIL Open Font License) are self-hosted in `assets/fonts/`. There is no build step.

Every dashboard on the page links to its live Streamlit app. Images showing the OpenCelliD tower-derived layer are shared under CC BY-SA 4.0.
